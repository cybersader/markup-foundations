# Inbox (Warm Zone)

Raw captures, quick notes, unprocessed discoveries.

**What goes here:**
- New articles, blog posts, or docs you want to read about markdown / Markdoc / MDX / expansion systems
- Quick observations: "Markdoc's `{% callout %}` syntax does X — investigate"
- Snippets of conversations or screenshots about markup oddities
- Links to plugin repos, editor projects, or SSG features to explore
- Questions to revisit ("does Quarto support nested directives?")

**Expected lifecycle:** Hours to days. Process regularly.

**Next step:** Promote to `[[01-working]]` for synthesis, skip to `[[02-learnings]]` if already distilled, or archive directly if it turns out to be a dead end.

> [!tip]
> Don't over-engineer captures. A title, a URL, and a one-line "why I saved this" is plenty. Frontmatter is optional in inbox — what matters is the capture happens.
