# Learnings (Cool Zone)

Distilled insights, atomic knowledge units. One insight per file.

**What goes here:**
- Crystallized insights from `[[01-working]]` drafts
- Findings from research worth preserving as standalone facts
- Atomic knowledge — one insight per file
- Use `YYYY-MM-DD-topic.md` naming convention

**Expected lifecycle:** Permanent.

**Next step:** Reference from `[[03-reference]]` survey docs, link via wikilinks across the vault, or file into `[[04-archive]]` only if superseded.

> [!tip]
> If two ideas fight for space in the same learning, split them into two files. A learning that needs sub-sections probably isn't atomic — it's a small survey, which belongs in `03-reference/`.
