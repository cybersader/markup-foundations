# Reference (Cold Zone)

Actively-consulted stable docs: surveys, landscape maps, guides, how-tos.

**What goes here:**
- Landscape surveys (e.g. "keystroke-time markup expansion: the ecosystem")
- Stable how-tos and patterns you actually consult
- Annotated source lists / external reference indexes
- First-principles primers on markup systems

**Expected lifecycle:** Permanent, actively maintained.

**Difference from learnings:** A learning is one atomic fact. A reference doc surveys, structures, or guides — it has sections and connects multiple learnings together.

**Difference from archive:** Reference docs are *actively consulted*. Archive docs are *filed away* and retrieved only via search.

**Next step:** When a reference doc stops being consulted, file into `[[04-archive]]`.
