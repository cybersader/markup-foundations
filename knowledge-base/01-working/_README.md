# Working (Active Zone)

Drafts in progress, active synthesis, opinions in formation, comparison documents.

**What goes here:**
- Position notes still in flux ("I think Markdoc beats raw shortcode systems — let me work through why")
- Comparison docs (Markdoc vs MDX vs Quarto for X use case)
- Drafts being built from multiple inbox captures
- Forming-opinion notes that aren't yet stable enough to be a learning

**Expected lifecycle:** Days to weeks.

**Next step:** Finalize to `[[02-learnings]]` (atomic insight), `[[03-reference]]` (stable survey/guide), or `[[04-archive]]` (the question went stale, archive what you've got).

> [!tip]
> A working note exists because you don't yet have a clean answer. If a working note sits with no movement for weeks, ask whether the question itself is still alive — if not, archive it rather than letting it rot here.
